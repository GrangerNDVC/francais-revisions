La Formation des Mots

À retenir

Les mots peuvent être simples (radical seul) ou construits (avec préfixes, suffixes, ou composition).

I. Mots simples et mots construits

Mots simples

Uniquement formés d'un radical. Ne peuvent pas être décomposés.

Exemples : mer, pont, jaune, carré, table, chien

Mots construits

Formés à partir d'un radical + préfixe(s) et/ou suffixe(s).

Exemples : revenir, déplaisir, invinible
II. La dérivation

On ajoute au radical (sens principal) des préfixes (avant) ou des suffixes (après).

Famille de mots : tous les mots formés à partir du même radical
Exemple : porter → importer, exporter, portable, porteur

Le radical

Élément minimal qui contient le sens principal du mot.

Exemple : illisible → radical lis- = lecture

Les préfixes (AVANT le radical)

Ils changent le sens du mot mais pas sa classe grammaticale.

Augmentatifs
  • supermarché
  • surdoué
  • archiconnu
Diminutifs
  • minijupe
  • soustitre
Privatifs (négation)
  • invisible
  • impossible
  • asocial
  • malheureux
Autres sens
  • prénom (avant)
  • coauteur (avec)
  • transpercer (à travers)
  • extrascolaire (en dehors)

Les suffixes (APRÈS le radical)

Ils changent le sens et peuvent changer la classe grammaticale.

Sens diminutif
  • maisonette
  • chaton
  • arbrisseau
Possibilité
  • faisable
  • éligible
Métier / Appareil
  • aviateur
  • ascenseur
Changement de classe
  • solide (adj) → solidité (nom)
  • piloter (verbe) → pilotage (nom)
  • lent (adj) → lentement (adv)
III. La composition

Mots formés de deux mots ou plus.

Mots composés avec trait d'union

Nom + nom
  • wagon-citerne
  • porte-avion
Nom + adjectif
  • rouge-gorge
  • grand-mère
Verbe + nom
  • coupe-circuit
  • porte-feuille
Verbe + verbe
  • laissez-passer

Mots composés avec préposition

  • pomme de terre
  • brosse à dents
  • homme d'affaires

Mots composés soudés

  • portefeuille
  • portemanteau
  • tournevis

Mots séparés par un espace

  • carte postale
  • chaise longue
IV. Les mots savants

Mots créés à partir d'éléments grecs ou latins.

Origine grecque

bios (vie) → biologie, biographie
graph (écriture) → graphologie, télégramme
phon (son, parole) → téléphone, phonétique
psycho (esprit) → psychologie, psychiatre
thermo (chaleur) → thermomètre, thermostat

Origine latine

ante (avant) → antérieur, antichambre
multi (nombreux) → multicolore, multimédia

Pièges à éviter

Préfixe ≠ Suffixe

PRÉfixe = AVANT le radical (ne change pas la nature)

SUFfixe = APRÈS le radical (peut changer la nature)

❌ Ne pas dire "le suffixe in-" → in- est un préfixe !

Le préfixe ne change pas la nature

heureux (adjectif) → malheureux (toujours adjectif)

Le suffixe peut changer la nature :

solide (adj) → solidité (nom)

Mots composés ou dérivés ?

Dérivé = radical + préfixe/suffixe (ex: refaire)

Composé = deux mots entiers (ex: porte-feuille)

Attention au trait d'union

Certains mots composés ont un trait d'union :

  • porte-avion ✅
  • arc-en-ciel ✅

D'autres non :

  • pomme de terre ❌ (espaces)
  • portefeuille ❌ (soudé)
