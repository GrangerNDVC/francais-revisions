La phrase : types, formes et voix

À retenir

3 types de phrase ⇔ 3 intentions : déclarative (constater), interrogative (questionner), impérative (ordonner).

Types de phrase ≠ formes de phrase

Les TYPES de phrases (l'intention)

Déclaratif : informer, raconter. Point (.) ou (...). Ex : "Il fait froid dehors…"

Interrogatif : questionner. Point (?). Totale (oui/non) : "Parles-tu français ?" / Partielle : "Où vas-tu ?"

Impératif : ordre, conseil. Point (.) ou (!). Ex : "Ferme la porte !" / "Ne pas toucher."

Exclamatif : exprimer une émotion. Point (!). Ex : "Quelle belle surprise !"

Les FORMES de phrases (la manière)

Affirmative : on affirme. Ex : "Je viendrai."

Négative : on nie (ne...pas, ne...jamais). Ex : "Je ne viens pas." / "Je n'ai jamais menti."

Exclamative : émotion, sentiment. Point (!). Ex : "La lionne est superbe !"

Emphatique : mise en valeur (c'est...qui/que, détachement). Ex : "C'est lui que j'ai vu."

Impersonnelle : "il" ne représente rien. Ex : "Il neige." / "Il faut partir."

Formes cumulées : plusieurs formes dans une même phrase. Ex : "Tu ne vas pas mettre ces chaussures !" (déclaratif + négatif + exclamatif)

Les VOIX du verbe (rapport sujet/action)

Active : le sujet fait l'action. Ex : "La souris mange le fromage."

Passive : le sujet subit l'action. Verbe = être + participe passé + "par". Ex : "Le fromage est mangé par la souris."

Pronominale : verbe avec pronom réfléchi (me, te, se...). Ex : "La souris se régale." / "Je me lave."

Pièges à éviter

Type ≠ Forme ≠ Voix

Une phrase peut cumuler type, forme et voix. Ex : "Ne sois-tu pas vu ?!" (interrogatif + négatif + passif)

Exclamation ≠ Impératif

Exclamatif : "Que c'est grand !" (émotion) / Impératif : "Va-t'en !" (ordre)

Passif ≠ Temps composé

"est mangé" (passif) / "est parti" (actif, temps composé). Astuce : ajouter "par quelqu'un".

Niveaux d'interrogation

Familier : "Tu viens ?" / Courant : "Est-ce que tu viens ?" / Soutenu : "Viens-tu ?"
